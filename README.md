# Student Task Manager

A beginner-friendly Flutter application for managing student tasks.

## Features
- Add a task
- View the task list
- Mark a task as completed or pending
- Delete a task
- View total, completed and pending task counts

## Requirements
- Flutter SDK
- Android Studio or Visual Studio Code
- Android emulator or a USB-connected Android phone

## Run the application
Open a terminal in this project folder and run:

```bash
flutter pub get
flutter run
```

## Important limitation
This is a classroom demonstration project. Tasks are stored in the app's in-memory list.
They reset when the app is restarted. No database, login system or cloud backend is included.
